Braço Robótico

Sistema de captura e replicação de movimentos humanos em tempo real

Apresentação do projeto

O projeto consiste no movimento dos dedos de uma mão do braço robótico utilizando o servo motores, Arduino e o Leap Motion. O projeto tem como objetivo a replicação de movimentos executados pelo utilizador. Para a captura dos movimentos utiliza-se o Leap Motion que é um dispositivo que capta o movimento das mãos do utilizador. Utilizando um software específico, pode-se visualizar e retirar os dados necessários para o movimento no braço.

Sobre o Projeto

Objetivo

O principal objetivo deste projeto é proporcionar uma solução inovadora que possa ser aplicada em ambientes educacionais, servindo como ferramenta de apoio ao ensino. Inspirado em práticas de fisioterapia das mãos, o sistema permite a replicação de movimentos humanos em um braço robótico, facilitando a aprendizagem prática e a demonstração de conceitos relacionados à robótica e reabilitação motora.

Ao integrar tecnologias como Arduino, servomotores e Leap Motion, o projeto busca simplificar tarefas e tornar o ambiente profissional e educacional mais eficiente, promovendo o desenvolvimento de competências técnicas e a inclusão de recursos tecnológicos no processo de ensino-aprendizagem.

Público-Alvo

O projeto foi desenvolvido para atender principalmente alunos e professores do ensino básico, secundário/profissional e técnico, com foco especial na educação inclusiva. Destina-se a beneficiar estudantes com limitações motoras nas mãos, oferecendo uma ferramenta adaptada que auxilia no processo de aprendizagem prática.


Além disso, professores podem utilizar o sistema como recurso didático complementar, promovendo a participação ativa de todos os alunos e integrando práticas de ensino inclusivo. O projeto contribui para a criação de ambientes educacionais mais acessíveis, inovadores e adaptados às necessidades específicas dos utilizadores.

Diagrama de Funcionamento

Na Figura observa-se o funcionamento do circuito. O projeto inicia-se com o utilizador que executa movimento com as mãos que são captados pelo sensor. Posteriormente envia os dados para o computador que os processa e envia para o Arduino, que controla o servo motor responsável pelo movimento dos dedos do braço.

Processo de Desenvolvimento

Fase 1: Desenvolvimento do Circuito Eletrónico

O projeto tem como objetivo a replicação de movimentos executados pelo utilizador. Para a captação dos movimentos utiliza-se o Leap Motion que é um dispositivo que capta o movimento das mãos do utilizador. Utilizando um software específico, pode-se visualizar e retirar os dados necessários para o movimento no braço. Os dados recolhidos ilustram a quantos graus está a inclinação dos nossos dedos. Esses dados estão associados ao respetivo nome do dedo em questão.

O Arduino recebe os dados do Processing, fazendo com que sejam executados pelo servo motor de acordo com os movimentos executados pelo utilizador. Esses movimentos servem para que os fios ligados entre o servo e a estrutura do braço sejam movidos de acordo com os dados recebidos pelo Processing.

Fase 2: Impressão 3D das Peças do Braço Robótico

Para realizar a impressão 3D começa-se por fazer o download dos STL. O site utilizado foi o Inmoov que é um site com o foco na criação de um robô. Os stl são grátis possibilitando que qualquer utilizador os possa utilizar.

Curiosidade: Os arquivos STL do InMoov são modelos tridimensionais usados para imprimir as peças do robô InMoov em impressoras 3D. Os arquivos fazem parte do projeto InMoov, um robô humanóide de código aberto criado por Gaël Langevin.

Para fazer a impressão das peças utilizam-se os serviços de uma empresa. São enviados os STL do braço e após alguns dias obtém-se a impressão.

Fase 3: Montagem Mecânica

Nesta fase faz-se a montagem de todas as peças impressas para criar o braço robótico funcional.

Fase 4: Montagem do Circuito Eletrónico

O processo da montagem foi realizado de forma sequencial. Inicialmente, ligaram-se os servos motores ao microcontrolador, e testado o seu funcionamento. De seguida, ligou-se o Leap Motion, assim como o microcontrolador ao computador para ver se estava tudo de acordo com o circuito planeado.

4.1 - Ligação dos Servos Motores ao Arduino

Nesta etapa, os servos motores foram conectados às portas digitais do Arduino, garantindo o correto funcionamento individual de cada motor antes da integração completa.

4.2 - Teste do Funcionamento dos Servos

Após a ligação, foi realizado um teste de funcionamento dos servos utilizando um código simples no Arduino para verificar movimentos básicos e identificar possíveis falhas.

4.3 - Integração do Leap Motion

O Leap Motion foi conectado ao computador e integrado ao sistema, permitindo a captura dos movimentos das mãos para posterior envio ao Arduino.

4.4 - Montagem Final do Circuito

Todos os componentes foram conectados conforme o diagrama, realizando a montagem final do circuito e testes de integração para garantir o funcionamento do sistema completo.

import com.leapmotion.leap.*;
import processing.serial.*;

Controller leap;
Serial myPort;

void setup() {
  size(800, 600);
  leap = new Controller();
  
  // Configura comunicação serial com Arduino
  String portName = Serial.list()[0];
  myPort = new Serial(this, portName, 9600);
  
  println("Leap Motion Controller inicializado");
}

void draw() {
  background(0);
  Frame frame = leap.frame();
  Hand hand = frame.hands().get(0);
  
  if (hand.isValid()) {
    // Captura dados da mão
    Vector palmPos = hand.palmPosition();
    Vector normal = hand.palmNormal();
    Vector direction = hand.direction();
    
    // Mapeia posições para servos
    int baseAngle = (int) map(palmPos.getX(), -200, 200, 0, 180);
    int shoulderAngle = (int) map(palmPos.getY(), 50, 400, 180, 0);
    int elbowAngle = (int) map(palmPos.getZ(), -200, 200, 0, 180);
    
    // Envia dados para Arduino
    String data = baseAngle + "," + shoulderAngle + "," + elbowAngle + "\n";
    myPort.write(data);
    
    // Exibe feedback visual
    drawHandData(palmPos, normal, direction);
  }
}

Robotic_Arm_Controller.ino 
#include <Servo.h>

Servo baseServo;
Servo shoulderServo;
Servo elbowServo;

int basePin = 9;
int shoulderPin = 10;
int elbowPin = 11;

void setup() {
  Serial.begin(9600);
  
  baseServo.attach(basePin);
  shoulderServo.attach(shoulderPin);
  elbowServo.attach(elbowPin);
  
  // Posição inicial
  baseServo.write(90);
  shoulderServo.write(90);
  elbowServo.write(90);
  
  delay(1000);
}

void loop() {
  if (Serial.available() > 0) {
    String data = Serial.readStringUntil('\n');
    
    // Processa dados recebidos
    int baseAngle = getValue(data, ',', 0).toInt();
    int shoulderAngle = getValue(data, ',', 1).toInt();
    int elbowAngle = getValue(data, ',', 2).toInt();
    
    // Move servos
    baseServo.write(constrain(baseAngle, 0, 180));
    shoulderServo.write(constrain(shoulderAngle, 0, 180));
    elbowServo.write(constrain(elbowAngle, 0, 180));
  }
}

String getValue(String data, char separator, int index) {
  int found = 0;
  int strIndex[] = {0, -1};
  int maxIndex = data.length() - 1;
  
  for (int i = 0; i <= maxIndex && found <= index; i++) {
    if (data.charAt(i) == separator || i == maxIndex) {
      found++;
      strIndex[0] = strIndex[1] + 1;
      strIndex[1] = (i == maxIndex) ? i+1 : i;
    }
  }
  
  return found > index ? data.substring(strIndex[0], strIndex[1]) : "";
}
